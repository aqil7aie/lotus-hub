## Lotus Hub 是什么？

Lotus Hub 是一款原生 Android 应用，可以全屏打开你的本地服务器，
就像独立应用一样：SillyTavern 及其分支，以及任何其他本地服务器。

## 它是如何工作的？

1. **添加服务器：** 名称 + 地址 + 可选的用户名和密码，然后点 **Save**。
   即使服务器处于离线状态也可以保存，而且不会打开服务器。
2. **点按卡片一次即可进入**服务器。
3. **长按卡片**可选择：编辑、删除、取消。
4. **Connect** 仅检测连通性（不打开、不保存），并显示结果和 HTTP 状态码。
   **Enter** 不保存，直接打开服务器。
5. 如果服务器要求输入 SillyTavern 的某个个人资料，请直接输入；
   否则，你也可以在服务器内部通过简单的步骤进行切换。
6. **提示：** 第一排卡片上方的一行小字会教你这两个手势。
   在一次长按和一次进入之后，它会永久消失，
   只有在清除应用数据后才会重新出现。
7. 图片和文件上传可在服务器内部完成（系统选择器）。
8. 服务器内的下拉菜单通过内置桥接工作，它会从实时页面读取真实选项。

## 构建步骤

每次推送到 `main` 时，CI 都会构建 release APK
（见 `.github/workflows/build.yml`）。本地构建需要 Android SDK + Gradle：

```
gradle :app:assembleRelease
```

签名密钥是私有的，永远不会放在这个仓库中。
